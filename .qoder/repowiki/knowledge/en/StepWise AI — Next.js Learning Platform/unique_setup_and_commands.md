Run `npm run dev` inside `stepwise ai/app/` to start the dev server on port 3000; copy `.env.example` to `.env.local` and set `AUTH_SECRET` before production. End-to-end verification is executed by `node e2e.mjs` against a running server, which performs the full signup → session → board → analyze → hint → complete → report flow and asserts ownership isolation and unauthenticated blocking.
