Single Next.js 14 app (app router) under `stepwise ai/app/`. The layering is: Route Handlers in `app/api/*` expose REST endpoints for auth, sessions, boards, reports, and the learning journey; they delegate to domain repos in `lib/` (`sessionsRepo.ts`, `journey.ts`, `auth.ts`) which own all persistence. Persistence is an embedded JSON store (`lib/db.ts`) backed by `data/stepwise.json` with a relational-style API (`all/get/insert/update/remove/transaction`) and a declared schema of ~20 tables; it is designed as a drop-in replacement for PostgreSQL via the same interface. Authentication uses Node `crypto.scrypt` password hashing plus httpOnly HMAC-signed session cookies stored in `auth_sessions`. The AI brain is abstracted behind `lib/ai/index.ts`, which selects between a `demoProvider` (offline mock) and `openaiProvider` based on `AI_PROVIDER` env, so the rest of the app never calls vendor SDKs directly. Domain types are centralized in `lib/types.ts` (session state machine, board objects, evaluation/hint models, concept mastery states, final report shape). UI pages live under `app/{home,journey,login,onboarding,report,sessions,settings}` and render via shared components in `components/`. An end-to-end script at `e2e.mjs` drives the full MVP loop against a running server to validate signup → session creation → board autosave → analyze/hint/complete → report generation and ownership isolation.
