Build the StepWise AI Visual Learning Engine.The Visual Learning Engine is responsible for creating, placing, updating, and intelligently using visual learning objects inside the StepWise Board.The Board is the PRIMARY WORKSPACE of StepWise.Visuals must not be decorative additions.Every visual created by the AI must have a learning purpose.The engine must determine:- When a visual would improve understanding.- Which type of visual is appropriate.- What information the visual should contain.- Where it should appear on the Board.- How it should relate to the student's work.- When it should be updated.- When it should disappear or be minimized.- How the student can interact with it.- How the AI can use the student's interaction with it as evidence of understanding.==================================================1. CORE PRINCIPLE==================================================The Visual Learning Engine follows:VISUALIZATION FOR UNDERSTANDINGNOTVISUALIZATION FOR DECORATION.A visual should answer:"Will seeing this help the student understand, reason, remember, compare, connect, or solve?"If the answer is no:Do not generate the visual.==================================================2. BOARD-FIRST DESIGN==================================================The Board is the central learning environment.The student should feel:"I am learning on this Board."Not:"I am chatting with an AI while looking at a whiteboard."AI explanations, diagrams, cards, graphs, maps, equations and student work should coexist on the same Board.==================================================3. VISUAL OBJECT TYPES==================================================Support visual objects including:- Diagrams- Concept maps- Mind maps- Flowcharts- Process diagrams- Timelines- Comparison cards- Information cards- Flashcards- Graphs- Charts- Mathematical visualizations- Scientific models- Labeled illustrations- Tables- Formula cards- Step cards- Cause/effect maps- Hierarchy trees- Cycles- Sequences- Relationship maps- Interactive examplesThe system should be extensible so new visual types can be added.==================================================4. VISUAL DECISION ENGINE==================================================Before generating a visual, internally evaluate:1. What is the student's current difficulty?2. What concept is being taught?3. Is the concept spatial, relational, procedural, numerical, comparative, or abstract?4. Would a visual reduce cognitive load?5. What visual type communicates it best?6. Should the visual be static or interactive?7. Should the student manipulate it?8. Should the student label it?9. Should the AI highlight a specific part?10. Is the visual necessary right now?Do not generate visuals automatically for every question.==================================================5. VISUAL PRIORITY==================================================Prefer visuals when the concept involves:- Structure- Spatial relationships- Processes- Cycles- Sequences- Systems- Comparisons- Graphs- Data- Geometry- Anatomy- Chemistry structures- Physics models- Historical timelines- Concept relationshipsPrefer text when text is clearer.==================================================6. AI-GENERATED DIAGRAMS==================================================The AI should be able to create educational diagrams.Example:Question:"Explain the water cycle."The Board can show:EVAPORATION↓CONDENSATION↓PRECIPITATION↓COLLECTION↓EVAPORATIONThe diagram should be visually clear and age appropriate.==================================================7. DIAGRAM STRUCTURE==================================================Every diagram should internally contain:- Diagram ID- Title- Concept- Objects- Relationships- Labels- Arrows- Explanation metadata- Board position- Size- Creation source- Interactivity stateExample:Diagram:PhotosynthesisNodes:SunlightWaterCO₂LeafGlucoseOxygenRelationships:Sunlight → energyWater → inputCO₂ → inputLeaf → processGlucose → productOxygen → product==================================================8. VISUAL HIGHLIGHTING==================================================The AI should be able to highlight specific parts of visuals.Example:Student struggles with the role of carbon dioxide.AI highlights:CO₂Then displays:🟣 LOOK HERE"This is the material coming from the air."The rest of the diagram remains visible but visually secondary.==================================================9. ERROR HIGHLIGHTING IN VISUALS==================================================If the student labels a diagram incorrectly:Student labels:"Stomach" → heartAI should highlight the incorrect label.Example:🔴 LABEL ERROR"Take another look at this structure."Then provide a targeted hint.Do not automatically replace the student's answer unless the student asks.==================================================10. STUDENT-ANNOTATABLE VISUALS==================================================AI-created visuals are:MOVABLEbut NOT directly editable in their internal structure.The student can:- Move them- Resize them- Rotate where appropriate- Add notes- Draw over them- Highlight them- Add arrows- Add text- Label them- Connect them to other objectsThe student cannot accidentally alter the underlying AI-generated diagram.==================================================11. WRITE ON VISUALS==================================================The student must be able to write on or around AI-generated visuals.Example:AI generates a cell diagram.Student adds:"nucleus = controls cell"The AI can analyze this annotation.The student's annotation remains separate from the original AI visual.==================================================12. VISUAL OBJECT LAYERS==================================================Use layers:Layer 1:Board background.Layer 2:AI visual.Layer 3:Student annotations.Layer 4:AI feedback/highlights.Layer 5:Temporary guidance.The system must distinguish these layers internally.==================================================13. MOVEMENT==================================================Every visual object should be draggable.Students can rearrange the Board according to their own thinking.Example:Student moves:CAUSEcloser toEFFECTThe AI may interpret the spatial relationship as possible evidence of understanding, but must not assume spatial placement always represents conceptual meaning.==================================================14. RESIZING==================================================Allow resizing.Maintain:- readability- aspect ratio where appropriate- minimum usable size- touch-friendly interactionPrevent accidental extreme resizing.==================================================15. BOARD CONNECTIONS==================================================Students can create relationships between objects.Examples:Arrow:Sunlight → PhotosynthesisText:"causes"Connection:Sunlight↓provides energy for↓PhotosynthesisThe AI should be able to understand these relationships.==================================================16. CONCEPT MAPS==================================================Concept maps should show relationships between concepts.Example:PHOTOSYNTHESIS├── requires → sunlight├── requires → water├── requires → CO₂├── occurs in → chloroplasts├── produces → glucose└── releases → oxygenThe student should be able to add their own nodes.==================================================17. MIND MAPS==================================================Mind maps should be useful for broad topics.Example:BIOLOGY├── Cells├── Genetics├── Ecology├── Evolution└── Human BiologyThe AI can automatically expand or collapse branches.Do not overwhelm the Board.Show only the relevant branch by default.==================================================18. STUDENT-GENERATED CONCEPT MAPS==================================================The student should be able to create a concept map manually.The AI can analyze it.Example:Student connects:Sunlight → FoodAI:🟡 PARTIALLY CORRECT"You're connecting sunlight with food production, which is important.What happens between these two ideas?"This makes the visual itself part of the teaching process.==================================================19. FLOWCHARTS==================================================Use flowcharts for processes.Example:Question:"How does blood move through the heart?"Visual:BODY↓RIGHT ATRIUM↓RIGHT VENTRICLE↓LUNGS↓LEFT ATRIUM↓LEFT VENTRICLE↓BODYThe AI can highlight the current stage being discussed.==================================================20. CYCLES==================================================For cyclical processes, use circular visual structures.Examples:- Water cycle- Carbon cycle- Krebs cycle- Cell cycle- Rock cycleThe AI should distinguish between:START → ENDandCYCLICAL PROCESS.==================================================21. TIMELINES==================================================For history and chronological concepts, use timelines.Example:1914↓World War I↓1918↓Treaty developmentsStudents can annotate events.The AI can ask:"What happened between these two events?"==================================================22. COMPARISON CARDS==================================================For comparison questions, generate side-by-side cards.Example:MITOSIS- One division- Two daughter cells- Growth/repairMEIOSIS- Two divisions- Four daughter cells- Gamete productionThen ask the student to identify the most important difference.==================================================23. INFORMATION CARDS==================================================Use compact cards for key concepts.Example:┌─────────────────────┐│ CHLOROPHYLL         ││                     ││ Pigment that        ││ absorbs light.      │└─────────────────────┘Cards should not become walls of text.==================================================24. INTERACTIVE CARDS==================================================Cards may support:- Reveal- Flip- Expand- Collapse- Compare- Sort- Match- LabelExample:Front:"What does mitochondria do?"Student answers.Then:"Reveal"AI evaluates the answer before revealing the explanation when appropriate.==================================================25. FLASHCARD MODE==================================================The Visual Engine should support flashcards as a learning tool.However, flashcards should remain connected to the current topic.Do not randomly generate unrelated flashcards.Example:Current topic:PhotosynthesisFlashcard:"What gas enters the leaf during photosynthesis?"Student responds.AI evaluates.==================================================26. GRAPHS==================================================Support educational graphs.Examples:- Line graphs- Bar graphs- Scatter plots- Pie charts where appropriate- Coordinate graphs- Scientific graphs- Motion graphsThe AI should understand the underlying data and meaning.==================================================27. STUDENT-DRAWN GRAPHS==================================================Students can draw graphs manually.AI should analyze:- axes- labels- scale- plotted points- trends- curve shape- unitsExample:Student draws distance-time graph.AI:🟠 CHECK THIS"Your time axis looks correct. Now check the slope between these two points."==================================================28. GRAPH INTERACTION==================================================Where appropriate, allow:- moving points- adjusting values- selecting points- drawing lines- changing variables- viewing labelsInteractions should create learning opportunities.==================================================29. MATHEMATICAL VISUALS==================================================Support visuals for:- Number lines- Geometry- Functions- Coordinate planes- Vectors- Fractions- Probability- Statistics- Algebraic relationshipsExample:Question:"What does 3/4 represent?"Generate a visual divided into four equal parts and ask the student to identify three parts.==================================================30. GEOMETRY==================================================Students should be able to:- inspect shapes- label sides- draw lines- mark angles- move points where appropriate- write measurementsAI evaluates mathematical relationships rather than artistic accuracy.==================================================31. SCIENCE MODELS==================================================Generate simplified educational models for:- cells- atoms- molecules- organs- ecosystems- forces- circuits- planetary systems- chemical reactionsThe visual must prioritize conceptual accuracy.==================================================32. DIAGRAM SIMPLIFICATION==================================================Complex diagrams should support levels.LEVEL 1:Simple overview.LEVEL 2:Major components.LEVEL 3:Detailed components.LEVEL 4:Advanced mechanisms.The AI chooses the appropriate level.==================================================33. VISUAL ZOOMStudents should be able to zoom the Board.Support:- pinch zoom- mouse wheel- zoom controls- fit to screen- focus on selected objectThe AI may automatically zoom/focus when explaining a specific detail.==================================================34. VISUAL FOCUSWhen the AI is discussing one part of a large visual:- focus camera on that area- highlight relevant component- dim irrelevant elements where appropriate- display a short explanationExample:"Look at this part of the cell."The nucleus becomes the visual focus.==================================================35. VISUAL PROGRESSIONDo not always show the finished diagram immediately.When pedagogically useful, build it progressively.Example:Stage 1:PlantStage 2:Add sunlightStage 3:Add waterStage 4:Add CO₂Stage 5:Show productsThis allows the student to build the concept mentally.==================================================36. HIDDEN INFORMATIONSome visual objects can intentionally hide information.Example:A diagram with missing labels.Student must fill:- nucleus- membrane- cytoplasmAI evaluates each label.This turns visuals into active learning rather than passive viewing.==================================================37. DRAG-AND-DROP LEARNINGSupport activities such as:"Drag each label to the correct part."or:"Arrange these steps in the correct order."AI should evaluate the resulting arrangement.==================================================38. MATCHINGExample:Match:Mitochondria → Energy productionNucleus → Genetic informationRibosome → Protein synthesisThe AI can use matching tasks as reinforcement.==================================================39. SORTINGExample:Sort these into:INPUTSandOUTPUTSStudent moves:CO₂WaterGlucoseOxygenAI evaluates.==================================================40. VISUAL ERROR DETECTIONWhen the student creates a visual representation, analyze:- incorrect labels- missing components- wrong relationships- incorrect directions- incorrect sequence- conceptual inconsistenciesDo not judge visual aesthetics unless relevant.==================================================41. VISUAL FEEDBACKFeedback should appear directly near the relevant object.Example:Student diagram:Sun → PlantAI adds:🟢 Correct relationshipStudent diagram:Soil → GlucoseAI adds:🔴 Concept errorThis keeps feedback connected to the student's reasoning.==================================================42. VISUAL FEEDBACK LABELSUse consistent labels:🟢 CORRECT🟡 PARTIAL🔵 MISSING🔴 ERROR🟣 THINK ABOUT THIS🟠 CHECK THIS⚪ UNCERTAINThe UI can later replace emojis with icons while preserving the semantic categories.==================================================43. AI VISUALS VS STUDENT VISUALSEvery visual must have ownership metadata:AI_GENERATEDSTUDENT_CREATEDIMPORTEDSYSTEM_GENERATEDAI-generated visuals should never be mistaken for student evidence.==================================================44. VISUAL ANALYTICSTrack meaningful interactions:- Visual opened- Visual moved- Visual annotated- Label added- Label corrected- Diagram completed- Diagram incorrectly completed- Hint requested- Visual explanation requested- Object relationship created- Visual task completedDo not treat every click as learning evidence.==================================================45. VISUAL UNDERSTANDING EVIDENCEStrong evidence includes:- Correctly labeling a diagram- Correctly connecting concepts- Correctly arranging a process- Correctly interpreting a graph- Correctly manipulating a model- Explaining why a visual relationship exists- Correcting a visual misconceptionWeak evidence:- Looking at a diagram- Moving an object randomly- Opening a card==================================================46. VISUAL + TEXT COMBINATIONThe strongest learning experiences may combine:Text+Diagram+Student annotation+AI feedbackExample:Student writes:"Sunlight gives the plant energy."Then draws:☀️ → 🌱AI evaluates both together.The visual and text should be treated as connected evidence.==================================================47. VISUAL + VOICEStudents can point to a visual and speak.Example:Student selects part of a heart diagram and says:"Blood comes here after it leaves the body."AI interprets:Selected region+Voice explanation+Current topicThen evaluates the reasoning.==================================================48. VISUAL + HANDWRITINGStudents can annotate diagrams using handwriting.Example:Student circles:"nucleus"and writes:"controls cell"AI should recognize both.==================================================49. VISUAL OBJECT SELECTIONWhen the student selects a visual object, provide contextual actions:🔍 Analyze💡 Hint❓ Explain🎨 Simplify✏️ Annotate🔗 Connect🗑 Remove📌 PinThe available actions should depend on the object type.==================================================50. VISUAL OBJECT LOCKINGAI-generated visuals can be locked against structural editing.Student can still:- move- resize- annotateunless the object is explicitly configured as movable-only.==================================================51. SAVE VISUALSStudents must be able to save:- entire Board- selected visual- current learning stateExport options should include image formats where supported.A saved Board should preserve the learning state visually.==================================================52. BOARD SNAPSHOTProvide:📸 Save BoardThis creates a snapshot containing:- student work- AI visuals- annotations- feedback- labels- diagrams- progress indicatorsThe snapshot should represent exactly what the student saw.==================================================53. VISUAL VERSION HISTORYWhere possible, maintain Board states.Example:VERSION 1:Initial attemptVERSION 2:After correctionVERSION 3:Final understandingThis can later be shown as a learning journey.==================================================54. VISUAL MEMORYThe AI should remember important visuals used during the session.If the student later asks:"What was that diagram we used earlier?"The AI should be able to locate or recreate the relevant visual.==================================================55. VISUAL REUSEIf a concept appears again in a future session, the AI may reuse a familiar visual structure.Example:The student previously learned the water cycle using a specific diagram.Later:"Let's use the water cycle diagram again."Do not unnecessarily create a completely different representation every time.==================================================56. VISUAL ACCESSIBILITYVisual learning must not depend entirely on color.Always support:- labels- icons- text descriptions- patterns- clear shapes- readable contrast- screen-reader-friendly descriptions where possibleExample:Do not communicate:"Red means wrong."Instead:"🔴 ERROR — This relationship is incorrect."==================================================57. CHILD-FRIENDLY VISUALSFor younger students:- larger objects- simple shapes- fewer elements- friendly illustrations- short labels- interactive activitiesAvoid overwhelming complexity.==================================================58. ADVANCED VISUALSFor university students:Allow:- detailed diagrams- formal graphs- technical models- equations- advanced concept maps- deeper relationshipsThe visual system should scale in complexity without changing its fundamental interaction model.==================================================59. VISUAL SIMPLIFICATIONEvery AI-generated visual should support:### SimplifyThe AI reduces complexity while preserving the learning objective.Example:Complex anatomy diagram→ simplified organ-level diagram.==================================================60. VISUAL EXPANSIONSupport:### Show MoreThe AI adds relevant detail.Example:Basic cell diagram→ organelles→ functions→ interactionsDo not reveal everything at once.==================================================61. VISUAL EXPLANATIONEvery important AI-generated visual can optionally provide:### Explain ThisThe AI explains:- what the visual represents- important parts- relationships- why it mattersThen returns control to the student.==================================================62. VISUAL QUESTIONSThe AI should be able to teach through visuals.Example:Instead of:"What is the mitochondria?"Show a cell diagram.Ask:"Which structure do you think is responsible for producing most of the cell's usable energy?"This creates visual reasoning.==================================================63. VISUAL CHALLENGESGenerate small challenges when appropriate:- Label this- Complete this- Find the error- Arrange these- Connect these- Predict what happens- Draw the missing part- Choose the correct relationshipThese should emerge naturally from the lesson.==================================================64. AI VISUAL CREATION PIPELINEWhen a visual is needed:CONCEPT IDENTIFIED↓VISUAL NEED DETERMINED↓VISUAL TYPE SELECTED↓CONTENT STRUCTURED↓VISUAL GENERATED↓ACCURACY CHECK↓AGE/DIFFICULTY ADAPTATION↓PLACED ON BOARD↓CONNECTED TO CURRENT LEARNING STEP↓MADE INTERACTIVE IF USEFUL↓AI OBSERVES STUDENT INTERACTION==================================================65. VISUAL ACCURACYEducational visuals must prioritize factual correctness.Before presenting a visual, verify:- labels- relationships- sequence- mathematical values- scientific structures- terminologyDo not generate attractive but scientifically incorrect diagrams.==================================================66. VISUAL SIMPLICITYAvoid unnecessary visual complexity.A beautiful diagram that confuses the student is a failed visual.Prefer:CLEAR→ SIMPLE→ RELEVANT→ INTERACTIVEover:COMPLEX→ DECORATIVE→ DISTRACTING==================================================67. BOARD SPATIAL INTELLIGENCEThe system should intelligently arrange AI-generated objects without taking control away from the student.New visuals should:- avoid covering student work- appear near relevant content- maintain readable spacing- preserve existing Board structure- avoid excessive clutterExample:Student answer on left.AI diagram appears on right.AI hint appears below the relevant object.==================================================68. AUTO-LAYOUTProvide optional:✨ Arrange BoardThe AI can intelligently organize the current Board.Possible arrangement:QUESTION↓STUDENT WORK↔VISUAL↓FEEDBACK↓NEXT STEPBut never delete student content.==================================================69. BOARD CLUTTER CONTROLIf the Board becomes crowded:Suggest:"Your Board is getting busy. Want me to organize it?"Options:[Organize][Keep As Is]Do not automatically rearrange the student's work without permission.==================================================70. VISUAL COLLAPSEOlder visuals can be minimized.Example:A completed concept card becomes:✓ Photosynthesis InputsClick to expand.This keeps the current learning area focused.==================================================71. CURRENT TOPIC PRIORITYThe Board may contain the student's entire journey, but the current topic should remain visually dominant.Previous topics should be accessible but visually secondary.==================================================72. VISUAL LEARNING JOURNEYImportant visuals can become part of the student's learning history.Example:Journey:🌱 Photosynthesis→ diagram created→ misconception corrected→ concept map completed→ mastery demonstratedLater the student can revisit the visual.==================================================73. VISUAL RECALLDuring future review:Show a partially completed familiar diagram.Ask the student to reconstruct it.Example:Previous:Sunlight → Photosynthesis → Glucose + OxygenReview:Sunlight → ______ → Glucose + ______This tests recall.==================================================74. VISUAL ADAPTATION FROM MISTAKESIf a student repeatedly confuses two concepts:Generate a comparison visual.Example:Student confuses:Voltage vs CurrentAI creates:VOLTAGE"push"CURRENT"flow"Then gives a contextual example.==================================================75. VISUAL LEARNING ENGINE OUTPUTEvery visual should produce structured metadata:Visual IDVisual typeTopicConceptLearning objectiveObjectsRelationshipsStudent annotationsAI annotationsOwnershipInteractivityDifficultyAge adaptationCurrent stateEvidence generatedRelated conceptsExample:Visual:Photosynthesis Flow DiagramLearning objective:Understand inputs → process → outputs.Student evidence:Correctly connected:Sunlight → energyIncorrect:Soil → glucoseAI action:Highlight misconception.Next:Ask student to reconsider source of glucose.==================================================76. FINAL PRINCIPLEThe Visual Learning Engine must make the Board feel like:A notebook+A whiteboard+A textbook+A diagramming tool+A laboratory+A concept map+An interactive tutorall combined into one intelligent learning space.But the visual system must never become the teacher itself.The visuals support the Teaching Engine.The Teaching Engine supports the AI Brain.The AI Brain supports the student's learning.The hierarchy is:STUDENT↓BOARD↓VISUALS + STUDENT WORK↓TEACHING ENGINE↓AI BRAIN↓KNOWLEDGEThe ultimate goal is not to make the Board look impressive.The ultimate goal is to make difficult ideas easier to SEE, THINK ABOUT, CONNECT, TEST, CORRECT, and REMEMBER.STEPWISE should make the student think:"I can actually see what I'm learning."
